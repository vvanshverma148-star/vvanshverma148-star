## What I've built

### [Medi-Evidence-AI](https://github.com/vvanshverma148-star/Medi-Evidence-AI)
A RAG-based medical research assistant that gives **citation-backed answers** instead of hallucinated ones. It pulls from PubMed, uploaded research PDFs, openFDA drug labels, DailyMed, and RxNorm, so every claim traces back to a real source. Built with Next.js and TypeScript.

**Why I built it:** LLMs are confidently wrong far too often for a domain like medicine. I wanted to see how far retrieval + citations could push reliability.

### [Budget-Mitra](https://github.com/vvanshverma148-star/Budget-mitra)
A price intelligence platform that answers *"should I buy now or wait?"* — not just *"where is it cheapest?"*. It tracks historical prices across Amazon, Flipkart and Myntra, runs 14-day price forecasts with Facebook Prophet, and sends alerts when a target price is hit.

**Stack:** Next.js + React frontend, Node/Express API with Bull queues, Python FastAPI ML service, MySQL, Redis.
